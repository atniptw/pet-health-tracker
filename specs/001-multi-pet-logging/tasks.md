# Tasks: Multi-pet symptom logging

**Spec**: [spec.md](spec.md) | **Plan**: [plan.md](plan.md)

Each task shipped as one or more commits, each safe to ship on its own.

- [x] T001 Theme: the design's colour tokens and the Figtree font.
- [x] T002 Symptom catalog: bundled and published, labelling logs. Number questions get a `unit`, and seizure duration is in seconds.
- [x] T003 Repository: create catalog logs, update single answers, and delete logs.
- [x] T004 Details screen: answer a catalog log's questions and edit its note from a pet's history.
- [x] T005 Providers: recent logs, recent `other` titles and the last-logged pet.
- [x] T006 Home and log sheet: the home screen with pet cards or avatars and recent logs, and the "Log a symptom" sheet that picks the pet, with "Something else…" and the "Logged before" chips. Logging happens only from the sheet, and the full-screen `other` form is kept for editing. The details screen gets the "Occurred {time}" row.
- [x] T007 Catalog symptoms in the log sheet.
